# Иконки и логотип

Клади файлы сюда: `d:\dev\IskraLauncher\renderer\assets\`
Всё подхватывается автоматически по имени, ничего в коде менять не нужно.

## Иконки в интерфейсе (шапка окна)

Любую можно заменить, положив файл `<имя>.svg` **или** `<имя>.png`.
Если файла нет — рисуется встроенная иконка-заглушка.

| Имя | Что заменяет |
|-----|--------------|
| `logo` | логотип слева в шапке (звезда) |
| `settings` | шестерёнка «Настройки» |
| `minimize` | синяя кнопка «Свернуть» |
| `close` | красная кнопка «Закрыть» |

Примеры: `settings.svg`, `logo.png`, `close.svg`.
SVG рекомендуется квадратный (`viewBox="0 0 24 24"`); PNG — от 64×64 с прозрачностью.

**Цвет:**
- `settings`, `minimize`, `close` — перекрашиваются в фиксированный цвет интерфейса
  (шестерёнка — белая, «Свернуть» — синяя, «Закрыть» — красная). Иконка берётся как
  силуэт по прозрачности, сам цвет в файле не важен; удобнее всего сплошной белый
  рисунок на прозрачном фоне;
- `logo` — берётся как есть, в полном цвете, не перекрашивается.

## Иконка приложения (окно / панель задач / .exe)

| Файл | Формат |
|------|--------|
| `icon.ico` | ICO с размерами 16/32/48/256 — иконка окна и `.exe` |
| `icon.png` | PNG 256×256 — запасная, если нет `icon.ico` |

Заглушки для всего этого генерирует `npm run icons`.
