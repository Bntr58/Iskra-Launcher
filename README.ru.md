# IskraLauncher

[English](README.md) · **Русский**

Небольшой портативный лаунчер для игр под Windows: список игр слева, большое превью справа и крупная кнопка **ИГРАТЬ**. Игры запускаются по ссылке-ярлыку (`steam://rungameid/...`, `roblox://placeID=.../`, `com.epicgames.launcher://...`) или по обычной командной строке из поля «Объект» ярлыка.

## Возможности

- **Список игр** с обложками. Невыбранные — обесцвеченные, выбранная — в цвете, с белой полосой и цветным названием. При наведении обложка увеличивается.
- **Разделители** — как папки в Steam: все игры под разделителем входят в его группу до следующего разделителя. Клик по разделителю сворачивает игры. У разделителя своё имя и цвет.
- **Превью** выбранной игры в белой рамке.
- **Кнопка «Играть»** запускает ссылку-ярлык через системный обработчик или локальную командную строку.
- **Перетаскивание** игр и разделителей для смены порядка в настройках.
- **Свои цвета** названия выбранной игры и кнопки «Играть».
- **Многоязычный интерфейс** — язык переключается в настройках, можно добавить свой (см. ниже).
- **Управление с клавиатуры**: `↑`/`↓` — выбор, `Enter` — запуск, `Esc` — закрыть настройки.
- **Портативность**: конфиг, обложки и переводы лежат рядом с exe, папку можно перенести на другой ПК.
- Окно без рамки, свободно меняет размер, вёрстка полностью резиновая.

## Установка

- **Установщик:** запусти `IskraLauncherSetup.exe`, выбери папку (внутри создастся подпапка `IskraLauncher`) и пройди мастер. Ярлыки добавятся в меню «Пуск» и на рабочий стол.
- **Портативно:** распакуй папку `IskraLauncher` куда угодно и запусти `IskraLauncher.exe`.

При первом запуске в списке только PORTAL 2. Открой настройки (шестерёнка слева сверху), чтобы добавить свои игры и разделители.

## Добавление игры

Настройки → **Добавить игру**: название, ссылка-ярлык (например `steam://rungameid/620`) и картинка. Подойдёт и командная строка из поля «Объект» ярлыка, например `"C:\Games\Foo\foo.exe" --launch`.

## Локализация

Все тексты интерфейса лежат в `localization/<код>.json` (сейчас `rus.json` и `eng.json`). Список языков в настройках строится из файлов в этой папке, пересборка не нужна.

Чтобы добавить язык:

1. Скопируй `localization/eng.json` в `localization/<код>.json` и переведи значения (ключи не трогай). Задай `common.languageName` — это имя в выпадающем списке.
2. По желанию добавь `<код> = <Имя>` в `localization/languages.txt` как запасное имя.
3. Перезапусти лаунчер — язык появится в настройках.

## Твои данные

Всё хранится рядом с `IskraLauncher.exe`:

- `config.json` — игры, выбранная игра, цвета, язык
- `images/` — обложки игр
- `localization/` — переводы интерфейса

Если папка только для чтения (например, `Program Files`), данные уходят в `%APPDATA%\IskraLauncher\`.

Деинсталлятор удаляет только файлы программы, а `config.json`, `images/` и `localization/` не трогает.
