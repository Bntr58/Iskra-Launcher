# IskraLauncher

![Preview](https://i.ibb.co/r23m0gQb/Untitled-3.png)

[English](README.md) · **Русский**

IskraLauncher — компактный портативный лаунчер игр для Windows. Список игр слева, крупный превью-постер справа и одна большая кнопка **PLAY** — вот и вся идея. Игры запускаются через shortcut-ссылки (`steam://rungameid/...`, `roblox://placeID=.../`, `com.epicgames.launcher://...`) или обычные командные строки, скопированные из поля *«Объект»* ярлыка.

![license](https://img.shields.io/badge/license-MIT-blue) ![platform](https://img.shields.io/badge/platform-Windows-lightgrey)

## Возможности

- **Обложки, а не просто названия**. Выбранная игра — в полном цвете со своим акцентом, остальные — обесцвечены. При наведении обложка увеличивается.
- **Папки в духе Steam**. Ставите разделитель — игры под ним объединяются в группу, которую можно свернуть одним кликом.
- **Крупный превью и одна большая кнопка Play**. Никаких меню, в которых нужно копаться.
- **Запускает что угодно** — Steam, Roblox, Epic ссылки или произвольную командную строку.
- **Перетащил — готово**. Порядок игр и разделителей меняется прямо в настройках.
- **Настрой под себя**. Свои цвета для каждой игры, свой файл перевода.
- Управление с клавиатуры: ↑/↓, Enter, Esc.
- Полностью портативный. Скопировал папку — забрал с собой.
- Аккуратно масштабируется. Окно без рамки, гибкая раскладка без фиксированных размеров.

## Установка

- **Через установщик** — запустите `IskraLauncherSetup.exe`, выберите папку (внутри неё создастся подпапка `IskraLauncher`) и пройдите мастер установки. Ярлыки в меню «Пуск» и на рабочем столе создаются автоматически.
- **Портативно** — распакуйте папку `IskraLauncher` куда угодно и запустите `IskraLauncher.exe`.

При первом запуске в списке будет только *Portal 2*. Откройте настройки (значок шестерёнки в верхнем левом углу), чтобы добавить свои игры и разделители.

## Добавление игры

В **Настройки → Добавить игру** укажите название, shortcut-ссылку (например, `steam://rungameid/620`) и выберите обложку. Подойдёт и любая командная строка, скопированная из поля *«Объект»* ярлыка — например:

```
"C:\Games\Foo\foo.exe" --launch
```

## Локализация

Весь текст интерфейса лежит в `localization/<code>.json` (сейчас есть `rus.json` и `eng.json`). Список языков в настройках формируется автоматически из файлов в этой папке — пересборка не нужна.

Чтобы добавить новый язык:

1. Скопируйте `localization/eng.json` в `localization/<code>.json` и переведите значения, не трогая ключи. Укажите `common.languageName` — это имя появится в списке языков.
2. По желанию добавьте строку `<code> = <Name>` в `localization/languages.txt` как резервное имя.
3. Перезапустите лаунчер — новый язык появится в настройках.

## Хранение данных

Всё хранится рядом с `IskraLauncher.exe`:

| Путь              | Содержимое                                  |
|-------------------|----------------------------------------------|
| `config.json`     | Игры, выбранная игра, цвета, язык            |
| `images/`         | Обложки игр                                  |
| `localization/`   | Переводы интерфейса                          |

Если эта папка доступна только для чтения (например, внутри `Program Files`), данные сохраняются в `%APPDATA%\IskraLauncher\`.

При удалении программы стираются только её собственные файлы — `config.json`, `images/` и `localization/` остаются на месте.
